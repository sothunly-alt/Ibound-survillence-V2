# Task: Fix ROI Tag Cutoff, Long Text Truncation, and Duplicate Overlapping ROI Layers

## Problem Summary

In the Inbound Garage Surveillance system (`edge/hub.html`, `edge/launcher.py`, and `src/dashboard/components/LiveView.tsx`):

1. **Tag/Badge Cutoff at Top Edge (e.g. Bay 4 "Coffee Zone" / "Trading"):**
   - When a service bay ROI box is placed near the top of the video screen (e.g., `y ≈ 0`), the bay's identification tag/chip (`.bay-chip`) is rendered with a static `top: -22px`.
   - Because `#video-stage` / `#video-viewport` has `overflow: hidden`, the tag is positioned outside the top boundary (`y < 0`) and is cut off / invisible.

2. **Long Text Truncation & Right-Edge Text Loss:**
   - The `.bay-chip` CSS specifies `left: 0; max-width: 240px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`.
   - When a bay is located on the right side or center-right of the screen (e.g., `x > 0.60`), the chip starts at the left of the box and extends 240px to the right, overflowing the right container boundary and getting chopped off.
   - Additionally, descriptive wording (e.g., `"Lift Bay 4 · ☕ ON BREAK - George (Paused: 12m 30s)"` or `"Trading Bay · 🔵 UNDER VEHICLE - Alex (1h 05m 20s)"`) easily exceeds 240px, causing the wording to be cut off with an ellipsis (`...`) even when screen space is available.

3. **Two Overlapping ROI Layers (Double ROI / Ghost Box):**
   - The video stream displays **two overlapping ROI rectangles**:
     - **Layer 1 (Uneditable baked-in layer):** The Python backend (`edge/launcher.py` lines 1357–1373) draws solid ROI rectangles, resize handle squares, and text directly onto the video frame pixels using OpenCV (`cv2.rectangle`, `draw_roi_handles`, `cv2.putText`) before encoding to MJPEG. These pixels cannot be clicked, dragged, or resized by the user.
     - **Layer 2 (Editable DOM layer):** The frontend (`edge/hub.html`) renders an interactive HTML/CSS overlay (`#roi-overlay`) with dashed borders (yellow for IDLE, green for WORKING, blue for UNDER VEHICLE), 8 drag handles (`.roi-handle`), and `.bay-chip`.
   - Having both layers active creates an ugly double-box glitch. When the user drags or resizes the frontend ROI, the yellow/green DOM box moves immediately, while the uneditable OpenCV box underneath stays fixed or lags behind.

## Root Causes Identified

### 1. Hardcoded Negative Vertical Offset on `.bay-chip` (`edge/hub.html`)
In [`edge/hub.html`](file:///home/george/Documents/Inbound-Surveillance/edge/hub.html#L136-L143):
```css
.roi-box .bay-chip {
  position: absolute; top: -22px; left: 0;
  font-family: "JetBrains Mono", ui-monospace, monospace;
  font-size: 10px; line-height: 16px; padding: 1px 6px;
  color: #000000; background: #00FF66; font-weight: 700; white-space: nowrap; max-width: 240px;
  overflow: hidden; text-overflow: ellipsis;
  border-radius: 2px;
}
```
- `top: -22px` is hardcoded regardless of the box's vertical position `y`.
- When `y < 0.04` (or `y * stageHeight < 22px`), `-22px` places the element above `y = 0px` (outside the stage).
- `#video-stage` has `overflow: hidden`, so any pixels above `0px` are clipped.

---

### 2. Static Left-Alignment and Fixed `max-width: 240px` (`edge/hub.html`)
- `.bay-chip` always anchors at `left: 0;`. If a box is near the right edge (`x = 0.85`), the chip starts at `85%` width and extends up to 240px past the 100% boundary, getting clipped off by `overflow: hidden`.
- `max-width: 240px` is too narrow for long bay names, multi-technician statuses, or pause timers generated by `stateBadge(bay)` in `edge/hub.html`:
  ```javascript
  bay.name + ' · ' + stateBadge(bay)
  // e.g.: "Lift Bay 4 · ☕ ON BREAK - Technician (Paused: 12m 30s)" -> ~55 chars (~380px)
  ```
- Any text over 240px is truncated into `...` and there is no dynamic adaptation to available screen width.

---

### 3. Backend Video Frame Burning in `edge/launcher.py` (`LiveStreamEngine`)
In [`edge/launcher.py`](file:///home/george/Documents/Inbound-Surveillance/edge/launcher.py#L1357-L1373):
```python
for snap in snapshots:
    color = bay_draw_color(snap.bay_id, snap.state)
    x1, y1, x2, y2 = roi_to_pixels(w, h, snap.roi)
    cv2.rectangle(annotated, (x1, y1), (x2, y2), color, 2)
    draw_roi_handles(annotated, (x1, y1, x2, y2), color)
    label = bay_badge(snap.state, snap.mechanic_name, snap.wrench_time_today, snap.technicians_times)
    cv2.putText(
        annotated,
        f"{snap.name}: {label}",
        (x1, max(24, y1 - 8)),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.5,
        color,
        2,
        cv2.LINE_AA,
    )
```
- `LiveStreamEngine` burns the ROI box, 8 handle boxes, and text label directly into the JPEG image buffer before streaming it via MJPEG to the browser.
- The browser simultaneously renders `#roi-overlay` containing DOM `.roi-box` and `.roi-handle` elements directly over the video stream.
- Result: **Two overlapping ROIs** (one uneditable in the video pixels, one editable in HTML/CSS).

### Step 3: Implement Boundary Flipping & Clamping in `layoutRoiOverlay()` (`edge/hub.html`)

In [`edge/hub.html`](file:///home/george/Documents/Inbound-Surveillance/edge/hub.html#L2582-L2600), update `layoutRoiOverlay()` and `syncBayDom()` to dynamically evaluate each bay's `x`, `y`, `w`, `h` coordinates against the stage dimensions:

```javascript
    function syncBayDom() {
      const overlay = document.getElementById('roi-overlay');
      if (!overlay) return;
      const keep = new Set();
      liveBays.forEach((bay, index) => {
        keep.add(bay.id);
        let el = document.getElementById('bay-box-' + bay.id);
        if (!el) {
          el = document.createElement('div');
          el.id = 'bay-box-' + bay.id;
          el.dataset.bayId = bay.id;
          el.className = 'roi-box border border-dashed cursor-move';
          el.innerHTML = '<div class="bay-chip"></div>'
            + '<span class="roi-handle nw" data-handle="nw"></span>'
            + '<span class="roi-handle n" data-handle="n"></span>'
            + '<span class="roi-handle ne" data-handle="ne"></span>'
            + '<span class="roi-handle e" data-handle="e"></span>'
            + '<span class="roi-handle se" data-handle="se"></span>'
            + '<span class="roi-handle s" data-handle="s"></span>'
            + '<span class="roi-handle sw" data-handle="sw"></span>'
            + '<span class="roi-handle w" data-handle="w"></span>';
          overlay.appendChild(el);
        }
        const color = bayColor(bay.id, index);
        const selected = bay.id === selectedBayId;
        el.classList.toggle('selected', selected);
        el.style.borderColor = color;
        el.style.background = color + (selected ? '33' : '18');
        const chip = el.querySelector('.bay-chip');
        if (chip) {
          chip.style.background = color;
          const fullLabel = bay.name + ' · ' + stateBadge(bay);
          chip.textContent = fullLabel;
          chip.title = fullLabel; // Full text on hover tooltip
        }
      });
      overlay.querySelectorAll('.roi-box').forEach((el) => {
        if (!keep.has(el.dataset.bayId)) el.remove();
      });
      const sel = selectedBay();
      if (sel) liveRoi = sel.roi.slice();
    }

    function layoutRoiOverlay() {
      const overlay = document.getElementById('roi-overlay');
      const stage = document.getElementById('video-stage');
      if (!overlay || !isStreamActive) return;
      overlay.style.left = '0';
      overlay.style.top = '0';
      overlay.style.width = '100%';
      overlay.style.height = '100%';
      syncBayDom();

      const stageW = (stage && stage.clientWidth) || overlay.clientWidth || 640;
      const stageH = (stage && stage.clientHeight) || overlay.clientHeight || 480;

      liveBays.forEach((bay) => {
        const box = document.getElementById('bay-box-' + bay.id);
        if (!box) return;
        const [x, y, w, h] = bay.roi;
        box.style.left = (x * 100) + '%';
        box.style.top = (y * 100) + '%';
        box.style.width = (w * 100) + '%';
        box.style.height = (h * 100) + '%';

        // 1. Top Edge Detection: Flip chip inside the box if top space is < 24px
        const boxTopPx = y * stageH;
        box.classList.toggle('chip-inside-top', boxTopPx < 24);

        // 2. Right Edge Detection: Align chip to right edge of box if placed near right edge
        const boxRightFrac = x + w;
        const shouldAlignRight = boxRightFrac > 0.70 || x > 0.55;
        box.classList.toggle('chip-align-right', shouldAlignRight);

        // 3. Dynamic Max-Width Clamping: Give chip maximum room up to the container boundary
        const chip = box.querySelector('.bay-chip');
        if (chip) {
          let maxAvailPx;
          if (shouldAlignRight) {
            maxAvailPx = Math.max(120, (x + w) * stageW - 8);
          } else {
            maxAvailPx = Math.max(120, stageW - (x * stageW) - 8);
          }
          chip.style.maxWidth = Math.min(480, Math.floor(maxAvailPx)) + 'px';
        }
      });
    }
```
